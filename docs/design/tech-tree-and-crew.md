# 科技树与成员组(设计稿)

> 负责人 2026-10-01 提出,主程整理。**三辆谢尔曼(012–015)完工后**开工;本文分「第一期要做的」和「以后再做的」两部分,第二部分只记录思路,时机成熟再细化成任务卡。
> 标「待确认」的地方是主程对原话的理解,开卡前请负责人确认。

## 1. 总原则

- 参考战争雷霆,但**大幅简化**:不做系别解锁、不做开线(研发)机制,现在只有三个国家、八辆车,全部直接可用。
- 成员组的成长不靠大量的时间和货币,而是「离线挂机升级」加「每个车族只训练一次」。
- 货币、研发、改装件等其他机制**本期都不做**。

## 2. 科技树(第一期)

参考战争雷霆手游的科技树:

- **横屏布局**:横轴是时代(按服役年份分阶,例如 1942 / 1943 / 1944 / 1945),从左往右越来越新。
- **每个国家占一行**(一个横条),**上下滚动切换国家**,滚动时按国家对齐(一次停在一个国家)。
- 每个国家的横条里,**按载具类别再细分成几条线**,例如轻型坦克、中型坦克、重型坦克、坦克歼击车 / 突击炮。没有车的类别不显示。
- **同一车族的车叠成一组**(像战争雷霆的「车组」卡片),点开展开。例如美国中型坦克线上的「M4A3 谢尔曼」组里是 M4A3(76)W、M4A3E8、M4A3E2。
- 点一辆车就是选中它,回到机库;机库底部现有的车辆列表可以保留成「最近使用」,也可以由科技树取代(**待确认**)。

现在的八辆车按这个规则大致是:

| 国家 | 类别 | 车 |
|---|---|---|
| 德国 | 重型坦克 | 虎式 E 型、虎王 |
| 苏联 | 中型坦克 | T-34-85 |
| 苏联 | 坦克歼击车 | SU-100、ISU-122 |
| 美国 | 中型坦克 | M4A3 谢尔曼组:M4A3(76)W、M4A3E8、M4A3E2 |

数据上需要给 `VehicleSpec` 加几个**可选**字段(改核心数据结构,开卡时由主程定):国家、类别、服役年份、车族。

## 3. 成员组(第一期)

### 3.1 结构

- 成员组(车组)属于某个国家,一个国家可以有好几个车组。
- 每个车组有一个**等级**,以及**已训练的车族**列表。
- **每个车族只训练一次**:训练过某个车族的车组,能开这个车族里的所有车。例如一个已经训练到 M4A3E8 的美国车组,也能直接开 M4A3E2 和 M4A3(76)W。
  - **待确认**:原话是「每个国家的每种车辆训练一次」。这里理解成「每个车组、每个车族训练一次」;如果意思是「同一国家的所有车组共享训练记录」,存档结构会不一样。
- 第一期**熟练度一律按 100%**:只要训练过这个车族,换车不掉熟练度。

### 3.2 离线挂机升级

- 车组下线后照样在成长:进游戏时按「上次离线到现在」的真实时间补算经验。
- 成长曲线用第 5 节的「对数增长 + 指数衰减」,第一期先用一组占位常数,能调就行。
- 存档放在本机浏览器(和设置一样),单机游戏不防改时间。

### 3.3 等级影响什么(提议,**待确认**)

现有数据里的装填时间、方向机 / 高低机速度都是 War Thunder「新手乘员」的值,WT 页面上同时有「王牌乘员」的值(例如谢尔曼 76 mm 装填 7.6 → 5.9 s)。提议:车组从 0 级到满级,这些数值在「新手」和「王牌」之间线性插值。这样不用编新数,出处现成。

## 4. 以后再做的(只记录思路)

1. **跨车族熟练度**:换到没训练过、但相近的车,熟练度打折。例如从「Easy Eight」换成「Jumbo」不可能保持 100%;从 ISU-152 换成 IS-2 掉得更多。需要定义车族之间的「相近程度」。
2. **载具试驾也积累经验**:在试驾 / 训练场里开车也给车组经验。
3. **单独给每个车组开「挂机训练」**:下线后车组在「虚空试驾」里攒经验,可以按车组开关、指定练哪辆车。
4. **成长曲线细化**:见第 5 节。

## 5. 成长曲线(第 4 节第 3、4 条要用,第一期先用占位常数)

负责人的描述:增长按对数曲线、用线性分段拟合;等级越高衰减越大,衰减按指数曲线、用线性分段拟合。整理成:

- **增长**:等级随挂机时间的变化接近对数曲线,前期涨得快、后期越来越慢:L(t) ≈ a · ln(1 + t / τ)。
- **衰减**:同样一小时的挂机,等级越高能换到的经验越少,衰减因子随等级按指数增长:每小时经验 ∝ e^(−λ·L)。两者是一回事的两种说法,实现时选一个当主公式,另一个用来校验。
- **线性分段拟合**:不在代码里直接算 ln / exp,而是按等级分段,每段是一条直线(查表 + 插值)。这样每一段的速度都能单独调,也方便在文档里列成表。
- 常数 a、τ、λ 和分段点,在开卡时按「多久升满级」反推(例如:挂机 7 天升到满级的 80%),**待确认**。

## 6. 本期不做

货币、研发 / 开线、系别解锁、改装件、技能点分配、成员个体(每个乘员单独的属性)。
