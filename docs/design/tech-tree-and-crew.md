# 科技树与成员组(设计稿)

> 2026-10-01 负责人已答复原先标「待确认」的四处(机库车辆列表、训练记录、等级影响、成长速度),本文已按答复改写;仍标「主程默认」的是负责人没提到、主程按 War Thunder 的做法补上的细节,有不同意见再改。

## 1. 总原则

- 参考战争雷霆,但**大幅简化**:不做系别解锁、不做开线(研发)机制,现在只有三个国家、八辆车,全部直接可用。
- 成员组的成长不靠大量的时间和货币,而是「离线挂机升级」加「每个车族只训练一次」。
- 货币、研发、改装件等其他机制**本期都不做**。

## 2. 科技树(第一期)

参考战争雷霆手游的科技树:

- **横屏布局**:横轴是时代(按服役年份分阶,例如 1942 / 1943 / 1944 / 1945),从左往右越来越新。
- **每个国家占一行**(一个横条),**上下滚动切换国家**,滚动时按国家对齐(一次停在一个国家)。
- 每个国家的横条里,**按载具类别再细分成几条线**,例如轻型坦克、中型坦克、重型坦克、坦克歼击车 / 突击炮。没有车的类别不显示。
- **同一车族的车叠成一组**(像战争雷霆的「车组」卡片),点开展开。例如美国中型坦克线上的「M4A3 谢尔曼」组里是 M4A3(76)W、M4A3E8、M4A3E2。
- 在科技树里点一辆车,就是把它分给当前编组里选中的车组(见 2.1),然后回到机库。

现在的八辆车按这个规则大致是:

| 国家 | 类别 | 车 |
|---|---|---|
| 德国 | 重型坦克 | 虎式 E 型、虎王 |
| 苏联 | 中型坦克 | T-34-85 |
| 苏联 | 坦克歼击车 | SU-100、ISU-122 |
| 美国 | 中型坦克 | M4A3 谢尔曼组:M4A3(76)W、M4A3E8、M4A3E2 |

数据上需要给 `VehicleSpec` 加几个**可选**字段(改核心数据结构,开卡时由主程定):国家、类别、服役年份、车族。

### 2.1 编组(取代机库底部的车辆列表)

机库底部现有的车辆列表改成「编组」,做法接近 War Thunder 的预设:

- **车组按国家分**:每个国家有若干个车组,这个国家的所有编组共用这批车组。车组数量以后可以招募增加;新车组的经验值暂定为 0。初始车组数开卡时按国家定(负责人举例:苏联 5 个、德国 2 个)。
- **编组 = 哪个车组开哪辆车**:一个国家可以有多个编组,玩家可以自由修改,能自定义名称。名称现在只是玩家自己的备注,例如苏联编组 1 叫「5.0-5.7」、编组 2 叫「6.7-7.7」;战斗权重(BR)机制以后再引入。
- **没分车的车组也显示**:苏联有 5 个车组时,编组 1 可以只给其中 3 个分了车,另外 2 个车组照样显示在底部,只是空白;编组 2 可以 5 个车组都分了车。德国只有 2 个车组,编组 1「5.7-6.7」底部就只有 2 格。
- **编组不能为空**:每个编组至少要有一辆可用的车。
- 同一个编组里,一辆车只能分给一个车组(**主程默认**,和 War Thunder 一样)。

## 3. 成员组(第一期)

### 3.1 结构

- 成员组(车组)属于某个国家,数量按国家分,见 2.1。
- 每个车组有一个**等级**,以及**已训练的载具**列表。
- **每个车组各自训练**:训练记录不在车组之间共享。
- **同车族换车保留熟练度**:车组 A 训练过 M4A3E8,想开 M4A3E2 或 M4A3(76)W 时不用再训练,熟练度保留。载具之间区别越大,保留的熟练度越低;怎么判定两辆车差多少,以后再细化(第 4 节第 1 条)。
- 第一期的简化:同车族按 100% 保留;换到别的车族要先训练,训练即时完成、不花钱(本期没有货币),训练后也按 100%。

### 3.2 离线挂机升级

- 车组下线后照样在成长:进游戏时按「上次离线到现在」的真实时间补算经验。
- 成长曲线用第 5 节的公式,只有一个常数 T,能调。
- 存档放在本机浏览器(和设置一样),单机游戏不防改时间。

### 3.3 等级影响什么(负责人已确认)

现有数据里的装填时间、方向机 / 高低机速度都是 War Thunder「新手乘员」的值,WT 页面上同时有「王牌乘员」的值(例如谢尔曼 76 mm 装填 7.6 → 5.9 s)。车组从 0 级到满级,这些数值在「新手」和「王牌」之间**线性插值**,插值比例就是第 5 节的成长进度 f(乘上熟练度)。这样不用编新数,出处现成。

## 4. 以后再做的(只记录思路)

1. **跨车族熟练度**:换到没训练过、但相近的车,熟练度打折。例如从「Easy Eight」换成「Jumbo」不可能保持 100%;从 ISU-152 换成 IS-2 掉得更多。需要定义车族之间的「相近程度」。
2. **载具试驾也积累经验**:在试驾 / 训练场里开车也给车组经验。
3. **单独给每个车组开「挂机训练」**:下线后车组在「虚空试驾」里攒经验,可以按车组开关、指定练哪辆车。
4. **成长曲线细化**:见第 5 节。

## 5. 成长曲线(负责人 2026-10-01 已定)

负责人的规则:挂机**两周升到满级的 50%**;之后每「再补上剩下的一半」,用时翻倍——50% → 75% 要 4 周,75% → 87.5% 要 8 周,以此类推,永远不会到 100%。

这条规则正好有一个闭式解。记 f 为成长进度(0 = 新手,1 = 满级),t 为累计挂机时间,T = 14 天:

- 升到 1 − 2⁻ⁿ 一共要 T · (2ⁿ − 1),反过来就是 **f(t) = t / (t + T)**。
  - 验算:t = 2 周时 f = 50%,t = 6 周时 75%,t = 14 周时 87.5%。
- **和对数的关系**:如果把「补上一半」的次数当作等级,n(t) = log₂(1 + t / T),正好是对数增长,也就是负责人说的「按对数曲线增长」。负责人提议的 ln(x^0.5) = 0.5 · ln x 形状相近,但 x = 0 时是负无穷、也不会停在 100% 以内,所以用上面这个式子:要在 ln 里加 1,系数是 1 / ln 2 ≈ 1.44。
- **越高越慢**:每小时的进度 df/dt = (1 − f)² / T,剩得越少涨得越慢,对应原先说的「等级越高衰减越大」。
- **离线补算**:当前进度 f₀ 相当于已经挂了 t₀ = T · f₀ / (1 − f₀);离线 Δt 后,f = (t₀ + Δt) / (t₀ + Δt + T)。一步算完,不用逐小时累加,也不需要线性分段拟合。
- 只有 T 一个常数,放在一处,以后想调快调慢只改它。显示给玩家的「等级」= f × 满级等级(满级等级开卡时定)。

## 6. 本期不做

货币、研发 / 开线、系别解锁、改装件、技能点分配、成员个体(每个乘员单独的属性)。
