# 战术标号规范与实现设计: 北约 (NATO) 与 华约 (Warsaw Pact)

本文档归档 039 任务卡中关于战术军标规范(北约 APP-6 / MIL-STD-2525 与 华约/苏军战术标号)的调研结果、矢量路径设计、版权声明、颜色偏差以及待负责人确认清单。

---

## 1. 背景与目标

在拟真地面装甲对抗游戏中，精确且符合军事规范的标图符号(Military Symbology)对战场态势感知至关重要。
过去 038 采用的是自绘的简单几何图形(菱形、实心菱形、下三角等)，存在语义不够严谨、无法体系化扩展的问题；若照搬商业游戏(如 War Thunder)的美术资源则存在版权与合规风险。

本项目全面转向公开的军事标图规范：
- **北约体系 (NATO Joint Military Symbology / APP-6 / MIL-STD-2525)**
- **华约/苏军体系 (Warsaw Pact / Soviet Ground Forces Tactical Symbology)**

两套符号提供统一的数据与渲染接口(`symbolShape`、`symbolSvg`、`drawSymbol`)，支持在设置面板中自由切换，并向前兼容游戏现有的大厅机库、科技树以及未来的小地图与战略地图界面。

## 2. 北约标号体系 (NATO APP-6 / MIL-STD-2525)

### 2.1 出处与依据标准
- **主要出处**: 
  - Wikipedia: [NATO Joint Military Symbology](https://en.wikipedia.org/wiki/NATO_Joint_Military_Symbology) (Allied Procedural Publication 6, APP-6 系列)
  - 美国国防部公开标号标准: MIL-STD-2525B/C/D (Common Warfighting Symbology)
  - 北约公开标图规程: NATO STANAG 2019 (APP-6A/B/C/D/E)

### 2.2 敌我识别框架 (Standard Identity / Affiliation Frames)
北约标准中，单位/装备的阵营(Affiliation)通过外部几何框(Frame)的形状与颜色共同决定：

| 阵营身份 | 框架几何形状 | APP-6 / MIL-STD-2525 标准色值 | 备注与几何定义 |
| :--- | :--- | :--- | :--- |
| **友军 (Friendly)** | 水平矩形 (Rectangle) | 蓝色 (`#00A8F0`, RGB: 0, 168, 240) | 横宽纵矮的长方形框，在 32×32 网格中为 `M 3 7 H 29 V 25 H 3 Z` |
| **敌军 (Hostile)** | 菱形 (Diamond) | 红色 (`#FF4D4D`, RGB: 255, 77, 77) | 旋转 45° 的正菱形，在 32×32 网格中为 `M 16 2 L 30 16 L 16 30 L 2 16 Z` |
| **中立 (Neutral)** | 正方形 (Square) | 绿色 (`#00C800`, RGB: 0, 200, 0) | 标准等边矩形，在 32×32 网格中为 `M 5 5 H 27 V 27 H 5 Z` |
| **未知 (Unknown)** | 苜蓿叶形 (Quatrefoil) | 黄色 (`#FFFF00`) | 游戏当前未开放未知目标，保留规范备查 |

*注：框体线宽统一为 2px，内部默认透明(`fill="none"`)。*

### 2.3 四种载具类型的符号与区分
在 APP-6 / MIL-STD-2525 的陆地装备/单位规范中：
- **装甲/履带底盘基准符号 (Armour / Track Icon)**:
  标准符号为水平圆角横椭圆(象征坦克的履带回路，Track loop)。在 32×32 网格中居中放置(宽 16，高 8)。
  出处：APP-6C Table 3-1: Ground Common Icons (Armor / Tracked Combat Vehicle).

四种车辆类型在北约标准下的细分定义：
1. **轻型坦克 (Light Tank)**:
   - **符号构型**: 履带椭圆 + 1 道居中垂直修饰线 (`|`)。
   - **出处**: APP-6D Section 4.3 及 MIL-STD-2525C 装备修饰符字段(Weight / Capability Modifier: Light, 代码 1.X.2.1.1.1)。在战术图元中用 1 条纵向细分线表示轻装甲/轻型。
2. **中型坦克 (Medium Tank)**:
   - **符号构型**: 履带椭圆 + 2 道垂直修饰线 (`||`)。
   - **出处**: APP-6D Section 4.3 (Weight / Capability Modifier: Medium, 代码 1.X.2.1.1.2)。
3. **重型坦克 (Heavy Tank)**:
   - **符号构型**: 履带椭圆 + 3 道垂直修饰线 (`|||`)。
   - **出处**: APP-6D Section 4.3 (Weight / Capability Modifier: Heavy, 代码 1.X.2.1.1.3)。
4. **坦克歼击车 / 突击炮 (Tank Destroyer / Self-Propelled Anti-Tank)**:
   - **符号构型**: 履带椭圆内部嵌套反坦克倒 V 楔形 (`∧`, Inverted Chevron)。
   - **出处**: APP-6C Section 3.2.1: Anti-Armor / Anti-Tank (AT) 功能符号为倒 V (象征穿甲破甲弹头/反坦克锥)。当倒 V 放置于装甲履带椭圆内部时，即构成公认的“自行反坦克炮/坦克歼击车”(Armor Anti-Tank / Self-propelled Tank Destroyer)标准复合标号。

## 3. 华约 / 苏军战术标图体系 (Warsaw Pact / Soviet Symbology)

### 3.1 出处与依据标准
华约与苏军在二战及冷战时期的野战标图采用与西方几何框不同的象形俯视战术图例。出处按优先级严格追溯：
1. **苏军经典条令与军官教材**:
   - 《Боевой устав Сухопутных войск》(苏联国防部陆军战斗条令, Часть 2: «Батальон, рота», Приложение: «Основные условные обозначения, применяемые в боевых документах»)
   - 《Рабочая карта командира》(指挥员工作地图, И.Д. Помбрик, Н.А. Шевченко, 军事出版局 Voenizdat)
2. **俄语维基百科条目**:
   - [Тактические условные знаки](https://ru.wikipedia.org/wiki/%D0%A2%D0%B0%D0%BA%D1%82%D0%B8%D1%87%D0%B5%D1%81%D0%BA%D0%B8%D0%B5_%D1%83%D1%81%D0%BB%D0%BE%D0%B2%D0%BD%D1%8B%D0%B5_%D0%B7%D0%BD%D0%B0%D0%BA%D0%B8) (战术条件符号)
3. **美军假想敌野战条令 (公有领域)**:
   - 美军陆军部公开出版物 FM 100-2-3: *The Soviet Army: Troops, Organization and Equipment* (Chapter 4 & Appendix: Soviet Tactical Map Signs)
   - FM 101-5-1: *Operational Terms and Graphics* (Soviet/Warsaw Pact section)
4. **兵棋与数字化模拟实践**:
   - 现代军事推演软件 *Command: Modern Operations (CMO)* 中的华约/苏军陆上战斗群标图标示 (参考 CMO, 非原始出处)。

### 3.2 华约/苏军标号形态与四种车型区分
苏军作战地图上的装甲车辆为非比例符号(внемасштабные условные знаки)，采用俯视轮廓示意法，由车体、炮塔(或固定战斗室)、延伸火炮身管三大要素构成：

1. **中型坦克 (Средний танк)**:
   - **符号构型**: 标准长圆角矩形车体 + 居中实心圆炮塔 + 向前(12点钟前进与射击方向)延伸的直线火炮身管。
   - **出处**: 《Боевой устав Сухопутных войск》附录「Танк」条目，苏联中型坦克(如 T-34-85、T-54/55)的标准战术地图标号。
2. **轻型坦克 (Легкий танк)**:
   - **符号构型**: 较窄扁的轻质车体轮廓 + 空心小型炮塔 + 较短火炮身管 + 车体单道划分。
   - **出处**: 《Рабочая карта командира》中对轻型侦察/水陆坦克(如 PT-76、T-26)的轻量标绘规定，并与中坦通过体量与单分划区别。
3. **重型坦克 (Тяжелый танк)**:
   - **符号构型**: 双重重装甲线条车体(двойной контур) + 大型炮塔 + 带炮口制退器(T形横划)的粗身管。
   - **出处**: 《Рабочая карта командира》第 3 章战术标号说明：重型坦克(如 KV-1、IS-2、IS-3)以加厚加宽车体及火炮制退器特征呈现。
4. **坦克歼击车 / 突击炮 (САУ / ПТ-САУ / Самоходно-артиллерийская установка)**:
   - **符号构型**: 履带车体 + 无旋转圆形炮塔的固定式梯形战斗室(рубка) + 前伸反坦克火炮与制退器。
   - **出处**: 苏军条令中 САУ(自行火炮/突击炮)的专属标号。由于 SU-85、SU-100、ISU-152 无独立回转炮塔，地图符号明确使用前部箱形战斗室凸起与大口径火炮标示。

## 4. 版权与独立矢量实现声明 (Copyright & Independent Vector Assets)

1. **公共标准属性**: 无论是北约 APP-6 / MIL-STD-2525 还是苏军战斗条令，战术标号规范本身皆属各国军方制订的公开条令标准，处于公有领域(Public Domain)。
2. **拒绝整份复制**: 本项目**绝不复制抓取**维基百科或其他商业矢量库(如 ArcGIS、Mapbox 等)上的现成 SVG 资产文件。
3. **独立代码路径实现**: 本项目的所有 SVG `<path>` 路径均严格基于条令中的几何文字定义与比例原则，在 32×32 网格坐标系中手工设计并编写数学坐标，完全自主可控，彻底规避任何美术版权争议。

## 5. 颜色约定与偏差说明 (Color Conventions)

1. **苏军真实历史习惯**:
   苏军传统的军图绘制规范中，**己方军队 (свои войска) 使用红色，敌方军队 (войска противника) 使用蓝色** (在单色图中己方为单实线，敌方为双线)。这与西方军标及现代电子游戏习惯恰好颠倒。
2. **游戏统一化偏差决策**:
   为了避免玩家在不同国家或切换符号体系时产生“看红是友、看蓝是敌”的认知混乱与误判，**本项目无论是北约符号还是华约符号，均统一遵循游戏的全局配色约定**：
   - **友军 (Friend)**: 统一使用蓝色 (`#00A8F0`)
   - **敌军 (Hostile)**: 统一使用红色 (`#FF4D4D`)
   - **中立 (Neutral)**: 统一使用绿色 (`#00C800`)
   - **被击毁 (Dead)**: 统一变灰 (`#888888`)，并居中叠加 `×` 标记。
3. **非战斗界面(科技树/机库)**:
   当不传递 `affiliation` 时，符号使用 `currentColor`，自动继承周围 UI 文字的颜色，适配暗色或高亮状态。

## 6. 将来扩展 (海军与空军标号)

当前任务卡(039)仅涉及陆战装甲与突击炮类型。未来若拓展海战与空战模式，接口与符号设计预留扩展方式如下：
- **空军 (Air Domain)**:
  - 北约友军空军采用拱形圆底框架(Arched bottom / Dome)，敌军空军采用倒 V 菱形顶；
  - 华约空军采用飞机正视/俯视两翼剪影。
- **海军 (Naval Domain)**:
  - 北约水面舰艇采用圆底矩形(Friendly Surface)与菱形顶(Hostile Surface)；
  - 华约海军采用舰首破浪楔形。
- 将来在 `SymbolOptions` 中仅需添加可选的 `domain?: 'land' | 'air' | 'sea'` 即可无缝延伸。
