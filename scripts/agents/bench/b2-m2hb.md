# B2:M2HB 重机枪零件(模型测试题)

- 规模:S(一个源文件 + 一个测试文件)

## 目标

用项目的程序化建模工具写一个新零件:**M2HB .50 口径重机枪(行军状态)连枪架**,以后谢尔曼的炮塔顶上会用到。

## 背景与参考

- 工具:`src/game/models/kit.ts`(`GeoBatch`、`box`、`cyl`、`tube`、`rod`、`extrude`、`loft`、`palette` 等);现成零件的写法看 `src/game/models/parts.ts`(比如 `periscope`、`shovel`、`towCables`),每个零件函数返回一个合并好的、带顶点色的几何体。
- 实物照片可以搜「M2HB Browning .50 cal」。

## 允许修改的文件

- 新增:`src/game/models/m2hb.ts`、`tests/m2hb.test.ts`

## 接口(定死,不要改)

```ts
/** M2HB .50 机枪(行军状态)连枪架,带顶点色 */
export function m2hb(c: Palette): THREE.BufferGeometry;
```

## 尺寸与坐标(按实物,允许 ±10%)

- 坐标:原点在枪架底座底面的中心(底座底面在 y = 0),**枪管朝 −Z**,+X 为右,+Y 为上。
- 枪架:底座 + 立柱 + 顶部的摇架,枪的轴线高度 y ≈ 0.40 m。
- 全长 1.65 m:枪口在 z ≈ −1.15,枪尾握把末端在 z ≈ +0.50。
- 机匣:长方体,约长 0.60 × 宽 0.15 × 高 0.20 m,后端有两个铲形握把和中间的扳机。
- 枪管:外径约 0.05 m,从机匣前端一直伸到枪口;根部有一段带散热孔的枪管套筒(长约 0.25、外径约 0.08 m),最前端有准星。
- 弹箱:挂在机匣**左侧**,约宽 0.10 × 高 0.28 × 长 0.25 m。
- 三角面不超过 800。颜色用 `Palette` 里的(枪身用 `c.dark` 或 `c.steel`,弹箱用 `c.paint` 或 `c.shade`)。
