### 031 科技树界面(Antigravity)

- **新增**:实现独立科技树组件 `TechTree` 与布局算法 `techTreeLayout`。
  - `techTreeLayout`: 纯函数, 将扁平车辆数据按年份轴(升序去重)、国家(德 -> 苏 -> 美)、类别(轻 -> 中 -> 重 -> 歼击)、车族分组成列排布, 支持车族中文名映射与无映射时回退至首车名。
  - `TechTree`: 全屏 DOM 组件, 顶部固定年份刻度与关闭按钮(支持 Esc 键), 每个国家一条全高横带并使用 CSS `scroll-snap` 纵向对齐切换; 单车直接展示, 多车族叠放为折叠卡片支持展开与收起; 支持当前出战车辆高亮(`currentId`)与当前编组车辆标记(`inLineup`), 点击车辆触发 `onPick(vehicleId)` 回调。
  - 在 `src/ui/menu/styles.ts` 末尾追加科技树样式, 保持与机库一致的黑金配色风格。
  - 新增 `tests/tech-tree-layout.test.ts` 与 `tests/tech-tree-ui.test.ts` (共 17 个测试全部通过)。
- **决策**:组件采用纯 DOM 实现, 独立于当前机库和主循环, 接口按任务卡定死, 为后续卡片接入编组与车组预留清晰的事件接口。
- **待确认**:无
